# 🧪 O Laboratório Secreto

Um jogo de *escape room* digital interativo construído com tecnologias web nativas (HTML5, CSS3 e JavaScript puro). Resolva enigmas, colete peças perdidas e restabeleça a energia do laboratório antes que o tempo acabe!

---

## 🚀 Como Executar

Como o projeto é inteiramente autocontido em um único arquivo, você não precisa instalar dependências, configurar Node.js ou rodar servidores locais.

1. Baixe ou clone o repositório contendo o arquivo `index.html`.
2. Dê um duplo clique no arquivo `index.html` para abri-lo em qualquer navegador web moderno (Google Chrome, Firefox, Safari ou Microsoft Edge).

---

## 🎮 Como Jogar

1. **Início:** Digite seu nome, escolha o nível de dificuldade desejado (Fácil, Normal ou Difícil) e clique em **"Entrar no laboratório"**.
2. **Desbloqueio Inicial:** Use a pista fornecida no painel da entrada para digitar a senha correta e liberar o mapa geral das salas.
3. **Exploração:** Navegue pelas salas através do mapa interativo. Cada sala possui um desafio único:
   * **Química:** Sequência correta de despejo de líquidos.
   * **Energia:** Soma binária de interruptores para atingir a carga exata.
   * **Arquivos:** Descriptografia de palavras baseada em cifras.
   * **Controle:** Jogo de memória com padrão de cores e sons.
   * **Oficina:** Resolução de padrões numéricos e sequências lógicas.
   * **Sala Secreta (Bônus):** Conexão correta de fios e terminais.
4. **Montagem Final:** Após coletar todas as 5 peças espalhadas pelas salas principais, acesse a **Sala da Máquina**, encaixe os componentes na ordem correta e puxe a alavanca para vencer o jogo!

---

## 🛠️ Tecnologias Utilizadas

* **HTML5** (Estruturação da interface e marcação semântica)
* **CSS3** (Estilização avançada, variáveis CSS, temas dinâmicos claro/escuro e animações)
* **JavaScript (ES6+)** (Lógica do jogo, controle de tempo, manipulação do DOM e gestão de estado)
* **Web Audio API** (Sons e bipes sintéticos gerados proceduralmente)
* **SVG Inline** (Ícones, avatares dos personagens e esquemas visuais das salas)
* **LocalStorage** (Persistência do placar de recordes e pontuações)
