# O-Laborat-rio-Secreto
O Laboratório Secreto é um jogo web de escape room em HTML, CSS e JavaScript puro. Ajude a Dra. Helena e o robô Tico explorando salas temáticas e resolvendo enigmas lógicos, matemáticos e de memória para recuperar 5 peças antes que a energia acabe. Conta com 3 dificuldades, ranking local, gráficos SVG e áudio nativo sem instalações.
